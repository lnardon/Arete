# Arete - Habits and Goals Tracker

![Habits Page](./demo1.png)

*It represents living up to one's best self, often viewed as a constant pursuit or journey rather than a final state.*

## Visit the app: [https://arete-production.up.railway.app/](https://arete-production.up.railway.app/)

### Features
- **Habit Tracking**: Monitor daily habits and routines to build consistency.
- **Goal Setting**: Define and track progress towards personal goals.(Month, Quarter, Semester, Year)
- **Progress Visualization**: Visualize your progress with charts and graphs.
